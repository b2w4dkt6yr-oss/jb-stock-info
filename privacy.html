작성 기준: 2026년 10월 12일 · 개인용 JB STOCK의 Google 연결과 본인 메일 발송에 관한 안내

1. 사용하는 정보와 목적

Google 계정의 이메일과 계정 식별자는 승인된 본인 계정과 발송 대상을 확인하는 데 사용합니다. 접근 token·갱신 token 등 인증정보는 Google 인증과 승인된 메일 발송에 사용합니다.

요청 권한은 openid, userinfo.email, gmail.send입니다. 이 OAuth 연결로 Gmail 메일함을 읽거나 메일을 삭제하지 않습니다.

2. 보관과 보호

인증정보는 본인 Mac의 Keychain에 보관합니다. 본인 이메일·발송 설정·연구 보고서·전송 결과·시험 확인 등 운영 기록은 본인 기기의 로컬 파일에 보관합니다. 인증정보를 공개 안내 페이지나 일반 보고서에 넣지 않습니다.

Google 계정 정보는 본인 확인과 승인된 전달을 위한 목적으로 사용하며, 판매·광고나 범용 AI 모델 학습에 사용하지 않습니다. Google API에서 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책의 제한적 사용 요건을 포함하여 준수합니다.

3. 외부 전달

메일 발송을 승인하면 연구 보고서의 허용된 본문과 JSON 첨부가 Google Gmail을 통해 본인 수신 계정으로 전달됩니다.

ChatGPT의 Gmail 읽기와 분석은 사용자가 OpenAI 서비스에서 별도로 승인하는 연결이며 해당 서비스의 정책이 적용됩니다. 이 연결에는 ChatGPT 결과를 JB STOCK에 자동 역저장하는 기능이 없습니다.

4. 중단·철회·보관

Gmail 연결 도구에서 발송을 끄거나 Google 계정의 타사 연결 관리에서 접근 권한을 철회할 수 있습니다.

발송 중지나 권한 철회가 기존 연구 기록·발송 기록·이미 받은 메일을 자동 삭제하지는 않습니다. 로컬 자료와 Gmail에 남은 메일의 보관·삭제는 본인이 관리합니다.

5. 공개 안내 페이지의 호스팅

이 안내 페이지는 GitHub Pages에 게시하기 위해 만든 정적 문서입니다. 페이지 자체에 로그인·정보 입력 양식·광고·분석 추적 도구를 설치하지 않습니다.

호스팅 제공자인 GitHub는 보안 목적으로 방문자의 IP 주소를 기록합니다. 자세한 처리는 GitHub 개인정보처리방침을 따릅니다.
